# MAI - IDL 2026 — Final Project Assignment
📌 Project Overview

This repository is the fully reconstructed and extended machine learning pipeline for BioHealth Diagnostics Global. The original codebase was destroyed in a sabotage incident. This repo contains:


✅ All four recovered scripts audited and fixed
✅ A new config.json to control all settings from one place
✅ An automated test runner built from scratch
✅ A lightweight model for energy-efficient deployment
✅ Transfer learning support for the small orgs dataset


The pipeline classifies medical images across 4 datasets using 3 model architectures.
